# 💗 Pink Music

> 一个 **不显示视频画面的 B 站网页浏览器** —— 基于 Electron + Vue 3 构建，专门用于收听 B 站的音乐内容。

## 💡 这个项目是什么？

简单来说，**Pink Music 相当于一个去掉了视频画面的 B 站网页端**。

它本质上做的事情和你用浏览器打开 B 站、搜索一首歌、然后最小化窗口只听声音，**没有任何区别**。只不过：

- 🖥️ 你不需要打开浏览器，它是个独立的桌面应用
- 🎵 你不需要看视频画面，它专注于音频播放
- 📂 你不需要手动整理，它帮你管理歌单

**它不下载 B 站的资源，不破解 B 站的接口，不存储 B 站的内容** —— 它只是在播放 B 站网页上原本就存在的音频流。

## ✨ 特色

- 🎵 **搜索播放**：在 B 站上搜索音乐相关内容，点击即播
- 🎶 **播放模式**：顺序、循环、单曲循环、随机
- 📂 **歌单管理**：创建、导入、导出个人歌单
- 🎨 **界面定制**：多主题配色 + 深色/浅色模式 + 毛玻璃效果
- 📑 **分P切换**：支持多章节内容的切换

## 🛠 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Electron | ^20.0.0 | 桌面应用框架（相当于浏览器的壳） |
| Vue 3 | ^3.5.32 | 前端框架 |
| Vite | ^8.0.4 | 构建工具 |
| axios | ^1.15.2 | 网络请求 |

## 📦 安装与运行

```bash
# 克隆项目
git clone https://github.com/Rayson-Liu/pink-music-app.git

# 安装依赖
npm install

# 启动开发服务
npm run dev

# 启动 Electron 客户端
npm run electron:dev
```

## 🔨 构建

```bash
# 构建 macOS 版本
npm run electron:build

# 构建 Windows 版本
npm run electron:build -- --win
```

## 🎮 使用指南

### 搜索与播放

输入关键词搜索 B 站上的音乐相关内容，点击卡片即可播放。

### 分P切换

播放内容含多章节时，点击右侧列表按钮切换。

### 歌单管理

侧边栏「创建」新建歌单，「导入/导出」支持 JSON 格式备份。

### 界面定制

右上角主题按钮切换配色与深色/浅色模式。
