# 💗 Pink Music

> 基于哔哩哔哩（B 站）公开接口的跨平台桌面音乐播放器 🎧🎶

非官方项目，与哔哩哔哩无任何官方关联或背书。

## ✨ 特色

- 🎼 支持登录 Bilibili 并获取收藏夹
- 🎧 高品质音频播放，优先拉取更高码率音频流
- 🔥 支持音频下载
- 🎚️ 10段均衡器 — 覆盖 31–16K Hz 全频段，±12dB 增益调节，提供 8 种预设曲线（流行/摇滚/爵士/古典/电子/人声/低音增强/默认）
- 📊 频谱可视化 — 大屏播放页实时音频频谱，自适应主题色，支持激进度调节
- 🎤 智能歌词 — 支持歌词显示/隐藏、手动搜索、逐行微调与重置
- 🧩 轻量界面，毛玻璃视觉效果与流畅动画
- 💿 系统托盘与最小化隐藏，便捷控制播放
- 🎨 6 套精美主题 — 提供粉色、紫色、蓝色、绿色、橙色，以及 Apple Music 风格主题
- 📂 本地歌单管理 — 支持创建、导入、导出 JSON 歌单，批量删除歌曲，一键播放整个歌单

git clone https://github.com/Rayson-Liu/pink-music-app.git

npm install

# 启动开发服务
npm run dev

npm run electron:dev
```

# 构建 Windows 版本

```

## 🎮 使用指南

### 搜索与播放

在搜索框中输入关键词，点击搜索按钮或按回车键进行搜索。点击音乐卡片直接播放。

### 分P切换

当播放的视频包含多个分P时，点击右侧列表按钮查看并切换分P。

### 歌单管理

- 创建歌单：点击侧边栏「创建」按钮
- 导入歌单：点击「导入」按钮，选择导出的 JSON 文件
- 导出歌单：在歌单页面点击「导出」按钮
- 批量删除：支持歌单内批量删除歌曲
- 一键播放：歌单封面/详情页「播放」按钮一键播放整个歌单

### 下载功能

在音乐卡片或歌单中点击下载按钮，音频将保存到下载目录，支持在下载管理器查看下载进度以及下载记录，支持在设置中调整音质。

### 界面定制

设置中的主题选项可以设置主题

### 均衡器

设置页提供「音频均衡器」面板，支持 10 段图式 EQ 调节：

- 频点：31 / 62 / 125 / 250 / 500 / 1K / 2K / 4K / 8K / 16K Hz
- 增益：±12 dB，步进 0.5 dB
- 预设：默认 / 流行 / 摇滚 / 爵士 / 古典 / 电子 / 人声 / 低音增强
- Draft + Apply 模式：拖动滑块只改草稿，点击「应用」才提交，避免频繁写入
- 持久化：所有配置自动保存，重启后恢复

### 频谱可视化

设置页提供「大屏播放页频谱可视化」开关与激进度控制：

- 频谱条贴底渲染，最大高度占屏 18%
- 自适应主题色，实时读取 CSS 变量
- requestAnimationFrame 驱动，窗口失焦/暂停时保留轻微呼吸动画

### 歌词

大屏播放页右上角提供「显示/隐藏歌词」开关：

- 支持自动匹配歌曲歌词
- 支持手动搜索歌词（按歌曲名重新匹配）
- 支持逐行微调偏移量，支持重置
- 歌词缓存引入作者维度，避免同名歌曲缓存冲突

### 界面定制

右设置中主题选项支持切换 6 种颜色主题（粉色/紫色/蓝色/绿色/橙色/Apple Music）和深色/浅色模式。
